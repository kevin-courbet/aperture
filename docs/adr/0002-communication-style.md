# ADR 0002: Communication Style

## Status

Accepted

## Decision

Aperture uses a calm, direct, and technical communication style adapted from
recurring patterns in Linear's public writing.

Aperture adapts the style to its technical context. It does not copy Linear
phrases. `DESIGN.md` contains the operational writing rules and examples.

## Independence

Aperture does not imply a relationship, affiliation, or endorsement by Linear.
